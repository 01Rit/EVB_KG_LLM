关键交互设计

1. 步骤卡片

  • 显示：组件名称、操作描述、时间、负责人、AS评分
  • LLM 序列额外显示：置信度百分比、grade 标签
  • 底部："查看推理链"按钮（仅 LLM 序列显示）

2. 推理链折叠面板

  • 论点列表：每条论点显示 layer badge + claim + confidence
  • 证据片段：超过 100 字截断，"展开更多"按钮
  • 综合置信度条 + grade 标签
  • overall_reasoning 总结文本

3. 甘特图

  • 保持不变，专注时序和资源调度
  • 推理链信息通过步骤卡片的折叠面板查看
